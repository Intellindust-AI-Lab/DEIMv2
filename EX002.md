# EX002: RGB phase 11.5

EX002 fine-tunes the HGNetv2-B2 DEIMv2 model on the two-class phase 11.5
RGB dataset. The class IDs are `person=0` and `head=1`.

## Data layout

Place the extracted images at:

- `/datadrive/data_phase11_5/train`
- `/datadrive/data_phase11_5/val`

The matching COCO annotations are tracked in `annotations/`.

## Training

Run from the repository root:

```bash
python3 train.py \
  -c configs/deimv2/deimv2_hgnetv2_m_phase11_5_EX002.yml \
  -t checkpoints/best_stg2.pth \
  --seed 0
```

The original run used PyTorch 2.5.1, torchvision 0.20.1, batch size 2,
102 epochs, and wrote checkpoints to `outputs/EX002_rgb_phase11_5`.
Its best validation COCO AP was 0.40956 at epoch 97.

## Video inference

```bash
python3 tools/inference/torch_inf_video.py \
  -c configs/deimv2/deimv2_hgnetv2_m_phase11_5_EX002.yml \
  -r outputs/EX002_rgb_phase11_5/best_stg2.pth \
  -i INPUT.mp4 \
  -o OUTPUT.mp4 \
  -l configs/dataset/phase11_5_labels.txt \
  --threshold 0.45
```
