# EX002: RGB phase 11.5

EX002 fine-tunes the HGNetv2-B2 DEIMv2 model on the two-class phase 11.5
RGB dataset. The class IDs are `person=0` and `head=1`.

## Data layout

Place the extracted images at:

- `/datadrive/data_phase11_5/train`
- `/datadrive/data_phase11_5/val`

The matching COCO annotations are tracked in `annotations/`.

## Training

Run from the repository root:

```bash
python3 train.py \
  -c configs/deimv2/deimv2_hgnetv2_m_phase11_5_EX002.yml \
  -t checkpoints/best_stg2.pth \
  --seed 0
```

The original run used PyTorch 2.5.1, torchvision 0.20.1, batch size 2,
102 epochs, and wrote checkpoints to `outputs/EX002_rgb_phase11_5`.
Its best validation COCO AP was 0.40956 at epoch 97.

## Video inference

```bash
python3 tools/inference/torch_inf_video.py \
  -c configs/deimv2/deimv2_hgnetv2_m_phase11_5_EX002.yml \
  -r outputs/EX002_rgb_phase11_5/best_stg2.pth \
  -i INPUT.mp4 \
  -o OUTPUT.mp4 \
  -l configs/dataset/phase11_5_labels.txt \
  --threshold 0.45
```

## Benchmarking a two-minute video

The video inference script reports both model-only CUDA time and end-to-end time
(video decoding, preprocessing, drawing, and encoding included). It also reports
peak PyTorch GPU memory and process RAM. Use the same input video, GPU, input
resolution, threshold, warmup, and output codec when comparing experiments.

```bash
python3 tools/inference/torch_inf_video.py \
  -c configs/deimv2/deimv2_hgnetv2_m_phase11_5_EX002.yml \
  -r outputs/EX002_rgb_phase11_5/best_stg2.pth \
  -i INPUT.mp4 \
  -o outputs/EX002_benchmark_bs1.mp4 \
  -l configs/dataset/phase11_5_labels.txt \
  --threshold 0.45 \
  --duration 120 \
  --batch_size 1 \
  --warmup 10 \
  --metrics_json outputs/EX002_benchmark_bs1.json
```

Repeat with `--batch_size 2`, `4`, etc. and a different output/JSON filename.
The training batch size for EX002 was 2; `--batch_size` above is the independent
inference batch size. If the input is shorter than 120 seconds, the whole input
is measured and the actual processed duration is recorded in the JSON file.

### Measured result (2026-07-23)

The command above was measured with an NVIDIA GeForce RTX 3060 (12 GB), PyTorch
2.5.1+cu124, FP32, inference batch size 1, 640x640 model input, and a 1280x720,
25 FPS source. The first 10 batches were excluded only from the model timing.

| Metric | Result |
|---|---:|
| Processed video | 120.00 s / 3,000 frames |
| End-to-end time | 105.52 s (28.43 FPS, 1.14x realtime) |
| Model + postprocess | 19.28 ms/frame (51.88 FPS) |
| PyTorch GPU peak allocated | 177.8 MB |
| PyTorch GPU peak reserved | 208.0 MB |
| GPU allocated increase while processing | 105.6 MB |
| Process maximum RSS | 1,713.3 MB |

The end-to-end result includes video decode, preprocessing, visualization, and
MP4 encoding. The GPU values are PyTorch allocator measurements; they do not
represent memory used by unrelated processes or the CUDA driver itself.
